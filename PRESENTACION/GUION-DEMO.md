# Guion de Demo (5-10 min)

## 1. Introduccion (1 min)
- Proyecto: Sistema de Incidencias y Servicios Comunitarios.
- Stack: Flutter + Node + MongoDB Atlas + Render.
- Roles: Admin, Profesional, Cliente.

## 2. Arquitectura (1 min)
- Mostrar diagrama: Flutter (Dio) -> API REST (Render) -> MongoDB Atlas.
- Mencionar JWT y Riverpod.

## 3. Demo - Cliente (3 min)
1. Login como cliente.
2. Dashboard del cliente.
3. Crear reporte de rescate (perdida, maltrato, etc.).
4. Ver mi reporte y cambiar estado a "Resuelto" (demuestra permisos).
5. Agendar cita veterinaria.

## 4. Demo - Admin (2 min)
1. Login como admin.
2. Dashboard con estadisticas.
3. Ver todos los reportes.
4. Cambiar estado de un reporte.
5. Gestionar categorias.

## 5. Cierre (1 min)
- Mostrar documentacion en GitHub (README, docs).
- Mencionar pendientes (APK).
- Preguntas.
